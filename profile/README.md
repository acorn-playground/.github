<h3 align="center">
  <a href="https://acornplayground.org">acornplayground.org</a>
</h3>

<p align="center">
  BBC Micros and Acorn Archimedes, on your Mac and in your browser.<br>
  Emulators that run them for real, a RISC OS ROM rebuilt from public source,<br>
  and tools to write and debug their programs in VS Code.
</p>

<p align="center">
  <a href="https://acornplayground.org/play/macbeeb"><b>Switch on a BBC Micro</b></a> ·
  <a href="https://acornplayground.org/play/macarch"><b>Switch on an Archimedes</b></a> ·
  <a href="https://acornplayground.org/play/mandelbrot"><b>Eight-BBC Mandelbrot</b></a><br>
  <sub>All three run right there, in your browser. No downloads, nothing to install.</sub>
</p>
